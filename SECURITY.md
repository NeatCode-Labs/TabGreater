# Security

TabGreater runs entirely on the device, holds no API keys and makes only public, unauthenticated requests to exchanges.

If you find a vulnerability, please open a GitHub issue at https://github.com/NeatCode-Labs/TabGreater/issues — or, if it should not be public yet, use GitHub's private vulnerability reporting on the repository. Please include the app version, the device and Android version, and steps to reproduce.

Only the latest release receives fixes.
